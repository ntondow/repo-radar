# Repo Radar

Single-file tool for finding trending GitHub repos and open-source building blocks.

- **Search** — topic presets and filters, ranked by stars/day, with Hacker News badges and README excerpts.
- **Build this** — describe what you're building; Claude splits it into components, searches GitHub for each, and ranks candidates for your stack. Needs an Anthropic API key (Settings; stored only in your browser).
- **Watchlist** — star repos, export as markdown.

No build step. `index.html` is the whole app. Live at https://ntondow.github.io/repo-radar/
